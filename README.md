# Générateur PAT — TPALF

Outil pour créer un plan d'appui (PAT) en actualisation linguistique en français à partir des descripteurs de la TPALF (primaire, moyen, intermédiaire, secondaire). Il produit un document Word.

## Utilisation
- **En ligne** : GitHub Pages → `index.html`.
- **Hors ligne** : ouvrir `index.html` par double-clic.

## Contenu
- `index.html` : version autonome, un seul fichier.
- `source/` : fichiers sources (descripteurs, synthèses, stratégies, générateur Word).

## Version
- Octobre 2026 : listes déroulantes (année 1re–12e, pays, 139 langues dont les créoles), calendrier pour les dates, synthèses des paliers TPALF dans l'outil et dans le Word.
